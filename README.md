# Virtual Art Workshop

## Іске қосу

Node.js 20 не одан жоғары нұсқасы орнатылған болса, осы қалтада терминал ашып:

```powershell
node serve.mjs
```

Содан кейін браузерде `http://127.0.0.1:4173` мекенжайын ашыңыз. Three.js осы жобаға бірге берілген. Тек қосымша қаріптер интернеттен жүктеледі; олар болмаса жүйелік қаріптер қолданылады.

Жұмыс өзгерістері автоматты түрде осы браузердің жергілікті жадына жазылады. Windows жүйесіне кіргенде Startup сілтемесі серверді кішірейтілген терезеде қосады; Node процесі тоқтаса, іске қосқыш оны қайта бастайды. Компьютер өшірулі не ұйқы режимінде болғанда жергілікті сайт қолжетімсіз болады.

## Қазіргі демо

- **Ағашты ою:** бетке сүйрегенде тығыз торлы 3D геометрия біртіндеп ойылады. Ағаш түрі, дайындама өлшемі, өрнек үлгісі және ойық тереңдігі өзгертіледі.
- **Күйдіру:** қаламды сүйрегенде мөлдірлігі мен қалыңдығы әртүрлі қоңыр із ағаш бетіне түседі.
- **Жону:** ваар, шатрын дүрс, багана, аяганы хэлбэрээс сонгож, эргэж буй 3D бэлдэцийн хөндлөн огтлолыг засварлана.
- Ажлын төлөвийг ижил хөтчийн localStorage-д хадгална. Файл сервер рүү илгээгдэхгүй.

Бұл — үш зертхананың интерактивті бірінші кезеңі. Оқушы/мұғалім кабинеттері, серверлік сақтау, өз оюын жүктеу, тапсырмалар бағасы және қалған зертханалар қосылмаған.
